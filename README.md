## BARRE DE PROGRESSION EN PLUSIEURS ETAPES

## Le challenge

Création d'une barre de progression en plusieurs étapes en HTML5 et CSS3.

Le cahier des charges est le suivant :

- Mise à jour de manière dynamique de la barre de progression au clic sur les boutons "Précédent" et "Suivant".

## Démonstration

Lien vers le projet : https://aperbet56.github.io/barre_de_progression_en_plusieurs_etapes/

## Projet développé avec

- Utilisation des balises sémantique HTML5
- CSS3
- Grid
- Flexbox
- Position absolute et position relative
- Animations CSS (transition)
- Utilisation d'un normaliseur : le fichier normalize.css
- Importation de la police "Sora"
- Desktop first
- Page web responsive
- Commentaires HTML
- Commentaires CSS
- JavaScript
- Code JavaScript commenté
